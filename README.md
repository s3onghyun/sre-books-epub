# SRE Books EPUB

Unofficial, non-commercial EPUB conversions of the official Google SRE books:

- *Site Reliability Engineering*
- *The Site Reliability Workbook*

The book content is unchanged. The EPUBs add only technical formatting for
e-ink reading, including a plain-text attribution page, responsive images, and
wrapping code blocks. They are not affiliated with or endorsed by Google.

Source: https://sre.google/sre-book/table-of-contents/ and
https://sre.google/workbook/table-of-contents/

## 한국어

공식 Google SRE 웹 도서를 전자책 리더에서 읽기 좋게 변환한 비상업적 EPUB입니다.
책의 본문은 변경하지 않았으며, 출처·라이선스 표기와 전자책용 기술적 서식만
추가했습니다. Google의 공식 배포물이나 보증을 의미하지 않습니다.
